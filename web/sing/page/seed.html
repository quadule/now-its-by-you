Words

A folk song passed between people and computers exploring music's ability to take on a life of its own, in verse and by embedding the software that sings it. Addressing the blurred authorship of AI music and code, its refrain asks the central question outright: “Who made this song? Nobody knows.”

Every copy is both an audio file and the same program that synthesized the song's instruments and vocals. Run it to get a new version, shaped by your computer and the season. Or, open the studio mode and change the words, melody, style, and mix. Sing along yourself, and a bit of your timing and inflection can influence the voice of future generations of the song. Or run the file

The song's file is also the program that sings it: an ordinary FLAC with a Python program packed inside. Run it with Python and you can create a new version, or edit and sing in the studio mode.

Windows

  1. Download the song ({{SEED_MB}} MB).
  2. Install Python 3.11 or newer from python.org.
  3. Open the folder you saved the song in, right-click an empty part of it and choose Open in Terminal.
  4. Type this, and press Enter:
py {{SEED_FILE}}

Mac or Linux

  1. Download the song ({{SEED_MB}} MB).
  2. You need Python 3.11 or newer. On a Mac, install it from python.org; most Linux systems have it already.
  3. Open a terminal and go to the folder you saved the song in. For most people that is cd Downloads
  4. Type this, and press Enter:
python3 {{SEED_FILE}}
{{INTEL}}

Before it changes anything it says what it will do, and asks. The first time, it downloads the libraries it needs (about 100 MB, from PyPI) into its own folder, .songbird in your home folder, which is all there is to delete; after that it needs no network, and nothing is sent anywhere. If you use uv, uv run python {{SEED_FILE}} needs no Python installed.

Who made it

The music you hear is made by a small computer program, and every version it sings is a little different. The program and its song were written with commercial generative AI models as collaborators. The finished program is not dependent on any online service; it runs on an average computer using traditional software synthesis methods for instrumentation and a small offline model for the voice.
