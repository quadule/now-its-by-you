# Documentation

**Now It's by You** is a folk song whose audio files carry the program that sings new versions of it. These
pages say how it works. Each is dated when it was written; the code is the final word.

## Start here

- [Running the song](RUNNING-THE-SONG.md): what you need to play, run and change a version.
- [The studio](STUDIO.md): making your own version, on your computer or at https://studio.itsby.you.
